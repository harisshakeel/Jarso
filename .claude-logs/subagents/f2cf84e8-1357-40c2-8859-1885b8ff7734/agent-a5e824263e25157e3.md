1. **Admin client built in the service** (`service.ts:5,38,104,176`)

   - The uuid is generated before the create call. If `createUser` returns an error after GoTrue has already saved the user (timeout or network drop), no cleanup runs and the auth user is orphaned.
   - Fix: on error, best-effort `deleteUser(id)` before throwing. The id is already known, so this is cheap.
3. **Role defaults to the privileged value** (`repository.ts:33-37`, `dal.ts:24-27`)
   - `findProfileRole` returns `"parent"` when no profile row exists.

4. **DAL redirect and authz logic has no tests** (`dal.ts:36-57`)

   - Anyone who knows a family's 6-char code can exhaust the 30/hour `pin:family` bucket and lock every child in that family out for an hour. A single IP can do this in about 16 minutes, given the per-IP limit of 20 per 15 minutes.

7. **Unauthenticated email with attacker-chosen text** (`service.ts:112-120`)

   - Fix: keep the nickname length cap strict in the schema.
8. **Signed-out child pages go to the parent login** (`dal.ts:36-37`)
