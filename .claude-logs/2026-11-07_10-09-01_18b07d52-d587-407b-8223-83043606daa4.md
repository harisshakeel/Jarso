## Key decisions
- **Sign-up works with email confirmation on or off.**
  - **Off (hosted today):** `supabase.auth.signUp` returns a session and the app goes straight to "About you".
  - **On:** there is no session, so a "Check your email" screen takes the code and calls `verifyOtp({ email, token, type: "email" })`. "Send again" is limited to once a minute.
  - **Code length:** the screen accepts 6 to 8 digits. The repo now sets `otp_length = 6` for production, but hosted stays at 8 until you push config.
  - **Errors:** every refusal shows the web's one calm line, and the log never contains the email or the code.
  - **One template, link and code:** Supabase has only one "Confirm signup" template, so `supabase/templates/confirmation.html` now has both the web link and the code (`{{ .Token }}`).
- **What "Your child calls you" covers:** it is on step 3's "About you" screen, as chips (Mum, Dad, Mama, Papa, Other…). It is written to `profiles.child_facing_name` just before the parent's details, through the existing `updateProfileById`. If that write fails it is logged and setup carries on.
- **Steps 4–7 run only for a family created in this run, and never when a `next` link is present.** That keeps the invite-link path working as before.
- **The QR holds `jarso://sign-in?code=<family code>&nickname=<nickname>` and nothing else.** No PIN, token or id.
  - **If it leaks:** it exposes the same two of three sign-in details as the printed card. The PIN, with its rate limits and lockout, still protects the account.
  - **Strict parsing:** the core parser `parseChildSignInLink` accepts only this scheme and path, a 4–16 character code and a valid nickname. It ignores `pin` and `next`.
  - **Stock camera:** the same link opens the app with the form filled in.
- **Freedom presets** (applied on top of a new child's defaults):
  - "Ask me every time" writes nothing.
  - "Small ones: just tell me" sets `withdrawal_auto_approve` and `deposit_auto_confirm` per item at a cap: 50 INR, 500 JPY, 5 in other currencies. Over the cap the child still asks.
